## User Story

As a **contributor**, I want a clearly licensed public repo, so that I can contribute confidently.

## Description

Make the project safe and welcoming to contribute to: clear licenses, contribution guidelines, security policy, and templates.

## Acceptance Criteria

- [ ] Core published under AGPLv3; docs under CC BY-SA 4.0.
- [ ] `CONTRIBUTING.md`, `SECURITY.md`, issue/PR templates.

## Technical Notes

Licenses are already in place (code AGPLv3, docs CC BY-SA 4.0). Remaining: community health files and templates.
